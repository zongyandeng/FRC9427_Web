Learning Library

新手工程學習資源

加入 FRC 的旅程充滿挑戰，我們將累積的工程技術整理成冊，幫助新隊員與同好們快速入門各項領域技能！

程式開發 / Java

WPILib 機器人控制入門

介紹 FRC 官方軟體庫 WPILib。學習如何使用 Java 控制底盤馬達、讀取極限開關與設定基本氣壓控制邏輯。

難易度: 適合新手 自學指引
3D 設計 / Onshape

Onshape 雲端機構建模指南

Onshape 瀏覽器建模基礎。本教程帶你熟悉草圖繪製、特徵擠出，以及如何組裝標準的 FRC 變速齒輪箱與支架。

難易度: 適合新手 影片教程
電子電路 / 配線

FRC 機電控制配線標準規範

介紹 RoboRIO 控制主機、PDP 電源分配板、馬達控制器與無線路由器 (Radio) 的標準配線圖解與安全絕緣處理。

難易度: 適合新手 PDF 規範
機械組裝 / 傳動

Swerve 舵輪底盤裝配與調試

Swerve 全向舵輪模組的組裝細節。解說齒輪齧合、培林安裝、角度感測器 (Encoder) 對齊與鏈條張力調整手法。

難易度: 中等難度 實作手冊
程式開發 / 自動導航

PathPlanner 自主移動路徑規劃

深入說明自主移動 (Autonomous) 階段的路線設計。如何運用 PathPlanner 工具繪製拋物線軌跡並載入 WPILib 執行。

難易度: 中等難度 核心技術
賽制規則 / 安全

FRC 賽場規則與安全防護守則

探索 FIRST 大賽的遊戲架構、分數計算規則，以及最核心的工場安全規範（護目鏡使用、手部防護及緊急停止安全開關）。

難易度: 適合新手 大賽導讀
